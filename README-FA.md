# راه‌اندازی فروشگاه MOBIX با گوشی

این پروژه یک نسخه شروعِ فول‌استک از فروشگاه MOBIX است. ظاهر راست‌چین و رنگ‌بندی سبز/سرمه‌ای حفظ شده و فایل HTML اولیه شما نیز با نام `public-original.html` داخل پروژه نگهداری شده است. سایت محصولات را از دیتابیس مرکزی می‌خواند؛ سفارش‌ها در دیتابیس ثبت می‌شوند و پنل مدیر امکان افزودن/حذف محصول و پیگیری وضعیت سفارش را دارد.

## قبل از شروع
برای انتشار عمومی به دو حساب رایگان/میزبانی نیاز دارید:
1. Supabase برای دیتابیس PostgreSQL و ورود مدیر: https://supabase.com
2. Vercel برای انتشار Next.js: https://vercel.com

هر دو را می‌توان با مرورگر گوشی مدیریت کرد. برای راحتی بیشتر، گوشی را افقی کنید یا گزینه «نسخه دسکتاپ» مرورگر را روشن کنید.

## مرحله ۱ ـ ساخت دیتابیس
1. وارد Supabase شوید و یک پروژه جدید بسازید. رمز دیتابیس را در جای امن نگه دارید.
2. از منوی SQL Editor یک Query جدید باز کنید.
3. محتوای فایل `supabase/schema.sql` را کامل کپی و اجرا کنید.
4. از بخش Authentication > Users یک کاربر مدیر بسازید (ایمیل و رمز قوی).
5. UUID کاربر ساخته‌شده را کپی کنید.
6. در SQL Editor این دستور را با UUID واقعی اجرا کنید:
   `insert into public.admin_users(user_id) values ('UUID-OF-ADMIN');`
   عبارت UUID-OF-ADMIN را با شناسه واقعی عوض کنید.
7. از Project Settings > API مقادیر Project URL و anon/public key را بردارید. کلید service_role را هرگز در سایت یا چت قرار ندهید.

## مرحله ۲ ـ انتشار کد
1. فایل ZIP را از حالت فشرده خارج کنید.
2. یک مخزن خصوصی GitHub بسازید: https://github.com
3. فایل‌های داخل پوشه پروژه را در مخزن بارگذاری کنید. در مرورگر موبایل می‌توانید از گزینه Add file / Upload files استفاده کنید.
4. در Vercel با GitHub وارد شوید، گزینه Add New > Project را بزنید و مخزن MOBIX را Import کنید.
5. در بخش Environment Variables دو مقدار زیر را وارد کنید:
   - `NEXT_PUBLIC_SUPABASE_URL` = آدرس پروژه Supabase
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY` = کلید anon/public
6. Deploy را بزنید. پس از پایان، آدرس عمومی سایت و مسیر `/admin` فعال می‌شود.

## مرحله ۳ ـ مدیریت فروشگاه
- آدرس `https://YOUR-SITE.vercel.app/admin` را باز کنید.
- با ایمیل و رمز مدیری که در Supabase ساخته‌اید وارد شوید.
- از بخش افزودن محصول، نام، توضیحات، قیمت و موجودی را وارد کنید.
- سفارش‌های ثبت‌شده در بخش سفارش‌ها دیده می‌شوند و وضعیت آن‌ها قابل تغییر است.

## نکات مهم و مواردی که هنوز باید تکمیل شوند
- پرداخت آنلاین هنوز متصل نیست؛ فرم فعلی سفارش را ثبت می‌کند و پولی دریافت نمی‌کند. برای پرداخت باید درگاه متناسب با کشور/شرکت ثبت‌شده فروشگاه و کلیدهای رسمی آن اضافه شود.
- بارگذاری فایل تصویر محصول و مدیریت دسته‌بندی‌ها، کوپن، ارسال، پیامک، گزارش مالی و محتوای صفحه اصلی در این نسخه پایه پیاده‌سازی نشده‌اند.
- موجودی در این نسخه هنگام ثبت سفارش رزرو/کسر نمی‌شود؛ برای فروش هم‌زمان پرتعداد باید ثبت سفارش با تراکنش اتمیک سمت دیتابیس تکمیل شود.
- سفارش‌های آزمایشی ممکن است اطلاعات تماس و آدرس داشته باشند؛ دسترسی مدیریتی را فقط به افراد مورد اعتماد بدهید.
- قبل از فروش واقعی، سیاست حریم خصوصی، شرایط مرجوعی، هزینه ارسال، مالیات و پشتیبان‌گیری را تنظیم کنید.

## اجرای محلی (اختیاری)
اگر روزی به کامپیوتر دسترسی داشتید: `npm install`، فایل `.env.example` را به `.env.local` کپی و مقادیر را وارد کنید، سپس `npm run dev`.
